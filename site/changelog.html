0.1.0 2026-09-07 5 commits

First working build enginesite

  • Engine. Collect, route, distribute, prove. Largest-remainder allocation so outlets sum to input exactly; time-weighted holder drip; Merkle claims with domain-separated leaves, promoted orphans and the index inside the leaf; conservation assertions that throw rather than settle. Zero runtime dependencies. Test suite of 42 cases, including one that loads the browser Merkle implementation and asserts it agrees with the engine byte for byte. 4e2898e
  • CLI. policy, cycle, verify, doctor. cycle --write-site writes the site's data file and the per-epoch claim files. Settlement signing is intentionally not wired to a key.
  • Site. Static, no framework. The fixture with a real water simulation; the routing diagram with droplets sampled off the pipe geometry; the dial console; the ledger with expandable epochs; the in-browser drip verifier; the parameters table; docs and this changelog. ccda773, 8059b56
  • Deploy. Vercel config with the build step as a policy guard, a strict CSP with no inline scripts, uncached data files, and a local server that applies the same headers. 602fbb8
  • Build stamp. Commit, branch, build time and test count written to data/build.json and shown in every footer.
